# Online learning

These models learn one sample at a time while the robot runs, and keep learning when the robot or its environment changes.

- **[Calibration](calibration.md)** — online Platt scaling: honest probabilities from any classifier.
- **[Metric learning](metric_learning.md)** — OASIS, LEGO and POLA, and a k-NN classifier that learns its distance online.
- **[Online classifiers](online_classifiers.md)** — robot-state classifiers that adapt to drift.
- **[Online dynamics](online_dynamics.md)** — learning the gap between the URDF model and the real robot's torques.
