# Shields

A shield sits between a signal and whoever uses it, and cleans it before it is used. Start here if you want one object that protects a whole series or a whole model.

- **[Armatura](armatura.md)** — wearable shield for one 1D series: a loss curve, a sensor channel, a token stream.
- **[Orca](orca.md)** — input and output shield for an entire model.
- **[Hybrid engine](hybrid_engine.md)** — the engine inside Armatura.
- **[Adaptive engine](engine.md)** — the engine inside Orca (Stage 1).
